## 📌 Project Overview

This is the official website for **Tamanna Computer & Photostat** — a trusted digital services hub located in **Upazila Parishad Gate Area, Lakshmipur Sadar, Lakshmipur, Chattogram, Bangladesh**.

The website was built with a **modern, premium dark-theme UI** featuring glassmorphism design, ambient glowing orbs, animated floating cards, and smooth scroll interactions — designed to attract and inform customers about the shop's services.

---

## ✨ Features

- 🌑 **Ultra-Modern Dark Theme** — Deep obsidian dark background with neon ambient glow effects
- 🃏 **Floating Glass Cards** — 3D perspective animated mockup panel in the Hero section
- ⌨️ **Typewriter Animation** — Dynamic typing of offered services in the hero subtitle
- 🎨 **Glassmorphism UI** — Frosted blur cards, floating pill navbar with backdrop filters
- 📍 **Embedded Google Map** — Live map showing the exact shop location
- 📱 **Fully Responsive** — Mobile-friendly slide-in drawer navigation
- ✅ **Service Checklist Cards** — Styled cards for each service with feature bullet points
- 📊 **Stats Counter** — Displaying years of experience in each domain
- 💫 **Scroll Animations** — Cards fade & slide in as you scroll using IntersectionObserver
- 📬 **Contact Form** — Client-side form with a beautiful success state

## 🚀 Getting Started

Clone the repository and open `index.html` in a browser — no build step required.

```bash
git clone https://github.com/tahsin-bit/Tamanna-Computer.git
cd Tamanna-Computer
# Open index.html in your browser
```

Or serve locally with:

```bash
npx serve .
```
